How I work with AI

I describe the intended behavior in a specification before implementing it. AI helps with code changes; I review the result against the acceptance criteria and tests. Reusable instructions and MCP tools provide project context.

  1. Define the problem

    User needs, constraints, assumptions and open questions.

  2. Describe the behavior

    States, acceptance criteria, cancellation, failure and recovery.

  3. Implement and review

    Read the code, compare alternatives and check the result.

  4. Record the results

    Tests, decisions and enough context for someone else to continue.
