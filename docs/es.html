Una especificación es un acuerdo de trabajo.

Utilizo IA con contexto reutilizable, skills y herramientas MCP. Los criterios de aceptación, la revisión de código y las pruebas permiten inspeccionar el trabajo.

  1. Definir

    Restricciones, supuestos y preguntas abiertas.

  2. Hacerlo comprobable

    Aceptación, fallos, cancelación y recuperación.

  3. Implementar y revisar

    Leer el código, comparar alternativas y preparar cambios revisables.

  4. Conservar la evidencia

    Pruebas, decisiones y contexto para otra persona o sesión.
