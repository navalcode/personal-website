Desarrollo asistido por IA

Parto de especificaciones y criterios de aceptación para orientar la implementación. Utilizo IA para investigar, desarrollar y revisar alternativas; contrasto los cambios con el código y las pruebas. Las decisiones documentadas y las herramientas MCP aportan contexto y continuidad.

  1. Definir el problema

    Necesidades del usuario, restricciones, supuestos y preguntas abiertas.

  2. Describir el comportamiento

    Estados, criterios de aceptación, cancelación, fallos y recuperación.

  3. Implementar y revisar

    Leer el código, comparar alternativas y comprobar el resultado.

  4. Registrar los resultados

    Pruebas, decisiones y contexto suficiente para que otra persona continúe.
